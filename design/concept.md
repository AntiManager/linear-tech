## 3. Визуальная концепция

### Стиль
- **Направление**: Industrial Clean — строгий, технический, без украшательств
- **Референсы**: SMC.eu (mega-menu), HIWIN.com (карточки продуктов), Misumi (фильтры)
- **Тон**: Экспертный, инженерный, без «продажного» маркетинга

### Цветовая схема
```
Основной:      #1A1A2E  (тёмно-синий, deep navy)      — хедер, футер, заголовки
Акцентный:     #E63946  (красный, industrial red)     — кнопки CTA, цены, акции
Дополнительный: #457B9D  (стальной синий)              — ссылки, иконки, разделители
Фон:           #F8F9FA  (светло-серый)                — основной фон страниц
Текст:         #212529  (почти чёрный)                 — основной текст
Второстепенный:#6C757D  (серый)                        — подписи, мета-информация
```

### Типографика
```
Заголовки:  Inter / Montserrat (sans-serif, geometric)
Текст:      Inter / SF Pro Display (высокая читаемость)
Моноширинный: JetBrains Mono / Fira Code (для артикулов, тех. данных)
Размеры:    H1: 36px, H2: 28px, H3: 22px, Body: 16px, Small: 14px
```

### Компоненты UI Kit
| Компонент | Описание |
|-----------|----------|
| **Mega-menu** | 3-колоночный. Категории слева, подкатегории в центре, промо-блок справа |
| **Карточка товара** | Фото продукта, название серии, 2-3 ключевые характеристики, цена / «Запросить цену», кнопки: «В корзину» / «Запросить КП» |
| **Таблица-каталог** | Для Rosca: колонки Ø, шаг, материал, длина, цена за шт/м, «В корзину» |
| **Фильтр параметрический** | Боковая панель: серия, размер (слайдер), материал, класс точности, чекбоксы |
| **Строка поиска** | Поле с автокомплитом по артикулам (HG25, FSI32-10, TR20x4R) |
| **Карточка наличия** | 🟢 В наличии (склад) / 🟡 Под заказ (срок) / 🔴 Нет |
| **Блок «Быстрая заявка»** | Телефон + «пришлите фото детали» — для ремонтников |
| **Таблица сравнения** | Выбор 2-4 товаров → сравнение характеристик |

## 6. Мобильная версия (Mobile First)

**Ключевой принцип**: 35-40% инженеров и снабженцев ищут детали с телефона (в цеху, на складе, в дороге).

| Элемент | Десктоп | Мобильная |
|---------|---------|-----------|
| Навигация | Mega-menu | Бургер-меню + поиск сверху |
| Каталог | Сетка 3-4 карточки в ряд | 1 карточка на всю ширину + sticky фильтр |
| Поиск | Поле в хедере | Выдвижная строка с автокомплитом |
| Карточка товара | Фото слева, данные справа | Фото сверху, данные снизу |
| Таблица Rosca | Полная таблица | Горизонтальный скролл + sticky заголовок |
| Корзина | Иконка в хедере | Плавающая кнопка внизу экрана |
| Контакты | В хедере и футере | Фиксированная кнопка «Позвонить» внизу |

## 7. SEO-стратегия (встроенная в дизайн)

- **Каждая категория** — отдельная посадочная страница с мета-тегами, H1, описанием
- **Хлебные крошки** (BreadcrumbList schema)
- **Schema.org**: Organization, Product (на карточках), BreadcrumbList, FAQ (на страницах FAQ)
- **ЧПУ (человеко-понятные URL)**: `/naznachenie-hiwin-hg/` вместо `/product?id=123`
- **Sitemap.xml** — авто-генерация из каталога
- **301 редиректы** со старых Joomla URL на новые
- **Alt-тексты** для всех изображений продуктов
- **Микроразметка** цен, наличия, рейтинга (если будут отзывы)

## 9. Анти-паттерны (чего НЕ делать)

- ❌ Скрытые цены — «узнать у менеджера» (бесит снабженцев)
- ❌ Табличные листинги без фильтров и картинок
- ❌ PDF вместо HTML-страниц каталога (PDF — дополнение, не замена)
- ❌ Тяжёлые слайдеры и анимации (B2B-аудитория ценит скорость)
- ❌ SEO-спам в футере (как на текущем linear-tech.ru)
- ❌ Регистрация для просмотра цен (цены показываем, регистрация — для заказа)
- ❌ Отсутствие мобильной версии
- ❌ Медленная загрузка (большие неоптимизированные изображения)
