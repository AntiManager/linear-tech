# linear-tech — System Patterns
> Updated: 2026-08-02

## Architecture
```
Browser → Next.js (SSR/ISR) → Strapi API → PostgreSQL
         static pages ← content build
         catalog, search, RFQ basket (CSR)
```

## Frontend Patterns (Next.js)
- Pages: SSR for content pages, ISR for catalog
- Components: functional React, Strapi data via API fetch
- Basket: RFQ (Request for Quote) model — client-side state, custom events for cross-component reactivity
- Images: WebP format, optimized, in `data/images-webp/`

## CMS Patterns (Strapi)
- Content types: Product, Category, Page, Article
- API: REST endpoints auto-generated by Strapi
- Admin: Strapi admin panel for content editors

## Encoding Rules (CONSTITUTION.md §0.1)
- **Критично**: весь контент сайта — русский (каталог HIWIN, статьи, интерфейс)
- Next.js: UTF-8 по умолчанию (TSX/JSX/JSON) — но проверять вывод SSR
- Strapi CMS: контент через API — проверять, что не разрушается при передаче между Strapi → Next.js
- Python-скрипты (`parse_site.py`, `download_media.py`): `encoding='utf-8'`
- Git: `i18n.commitEncoding = utf-8`, `core.quotepath = off`
- API-запросы к Strapi: принимать контент как UTF-8, не допускать двойной перекодировки
