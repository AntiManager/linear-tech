# Stack Comparison — B2B Industrial Site

## Критерии оценки

| Критерий | Вес | Как оцениваем |
|----------|-----|---------------|
| Производительность (LCP, TTFB) | 25% | Lighthouse, WebPageTest |
| Total Cost of Ownership (TCO) | 20% | Лицензии + хостинг + разработка + поддержка / год |
| Гибкость дизайна и UX | 20% | Полный контроль над HTML/CSS vs шаблоны |
| SEO-возможности | 15% | SSR/SSG, meta-теги, schema.org, sitemap |
| Скорость разработки | 10% | Готовые компоненты, экосистема |
| Интеграция с Битрикс24 | 5% | API, webhooks, готовые модули |
| Безопасность | 5% | OWASP, CVE-история, патчи |

## Кандидаты для сравнения

### 1. Next.js 14 + Strapi (Headless CMS)
```
Frontend:  Next.js 14 App Router + React 18 + Tailwind CSS
Backend:   Strapi 5 (self-hosted, OSS)
DB:        PostgreSQL
Search:    Meilisearch (OSS)
Cache:     Redis
Deploy:    Docker Compose on VPS
CDN:       Cloudflare (free tier)
```
**Плюсы**:
- Максимальная производительность (SSG/ISR/SSR)
- Полный контроль над дизайном (не привязан к шаблонам CMS)
- Strapi — удобная админка для менеджеров (не нужен программист для обновления контента)
- Бесплатно (OSS), только хостинг
- TypeScript из коробки, строгая типизация
- Весь мир на Next.js — легко найти разработчиков

**Минусы**:
- Два приложения (Next.js + Strapi) = сложнее деплой
- Нужен npm-пакет для Битрикс24 (ручная интеграция)
- Требуется разработчик со знанием React/Next.js

**Оценка**: ⭐⭐⭐⭐⭐ (рекомендовано)

### 2. Django + HTMX / Alpine.js
```
Backend:   Django 5 + Django REST Framework
Frontend:  Django Templates + HTMX + Alpine.js + Tailwind
DB:        PostgreSQL
Search:    PostgreSQL full-text search + trigram
Cache:     Redis
Deploy:    Gunicorn + Nginx on VPS
```
**Плюсы**:
- Монолит: всё в одном проекте
- Django Admin — мощная админка из коробки
- Python — знакомый стек
- ORM, миграции, админка из коробки

**Минусы**:
- Нет SSR/SSG из коробки — хуже производительность
- Шаблоны Django менее гибкие чем React
- HTMX — нишевая технология, сложнее найти разработчиков
- Мобильная производительность хуже чем у Next.js

**Оценка**: ⭐⭐⭐⭐

### 3. 1С-Битрикс (как у конкурентов)
```
CMS:       1С-Битрикс: Управление сайтом (редакция «Бизнес»)
DB:        MySQL
Search:    Встроенный поиск Битрикс
Cache:     Встроенный композитный кеш
Deploy:    LAMP/LEMP на VPS
```
**Плюсы**:
- Интеграция с 1С и Битрикс24 из коробки
- Готовые модули (интернет-магазин, каталог)
- Знакомо заказчику (Rosca уже на Битрикс24)
- Не нужен Node.js
- Конкуренты на нём же — значит, работает

**Минусы**:
- Лицензия: от 150 000 ₽/год (редакция «Бизнес»)
- Тяжёлый монолит — медленная загрузка
- Дизайн ограничен шаблонами/компонентами
- PHP — устаревающий стек для фронта
- Зависимость от вендора (обновления, безопасность)
- Плохая мобильная производительность

**Оценка**: ⭐⭐⭐

### 4. Размещение всей продукции на Битрикс24 (лендинг + CRM)
```
CMS:       Битрикс24 Сайты (конструктор)
CRM:       Битрикс24 (уже используется для Rosca)
```
**Плюсы**:
- Rosca уже там — единая платформа
- CRM + сайт в одном месте
- Не нужно программировать бэкенд
- Быстрый запуск

**Минусы**:
- Конструктор сайтов очень ограничен (нельзя сделать каталог как у Зетек)
- Нет параметрического поиска и фильтров
- SEO страдает (конструкторы генерируют плохой HTML)
- Производительность низкая
- Полная зависимость от облака Битрикс24

**Оценка**: ⭐⭐ (только для лендинга Rosca, не для каталога HIWIN)

### 5. Мегаплан Б — сделать на Python-парсере
С парсера написать генератор статического HTML → залить на Netlify/Cloudflare Pages.
**Оценка**: ⭐ (только для архивной копии, не для живого каталога)

## Рекомендация

**Next.js 14 + Strapi 5** — оптимальный выбор для данного проекта.

**Почему не Битрикс**:
1. Лицензия съедает бюджет (~150 000 ₽/год), который лучше потратить на разработку
2. Дизайн будет выглядеть как у конкурентов (все на Битриксе выглядят одинаково)
3. Производительность ниже — а для B2B это критично (инженеры уходят с медленных сайтов)

**Риски Next.js + Strapi**:
- Нужен разработчик React/Node.js → **митигация**: закладываем в бюджет
- Интеграция с Битрикс24 — ручная работа → **митигация**: используем REST API + вебхуки Битрикс24
- Деплой сложнее → **митигация**: Docker Compose + CI/CD GitHub Actions

## Альтернатива Next.js + Strapi: Astro + Strapi
Если нужна ещё более высокая производительность и меньшая сложность — можно использовать Astro вместо Next.js.
Astro отправляет ноль JS по умолчанию (идеально для каталога), но для интерактивных элементов (фильтры, поиск) подключаются React/Vue/Svelte «острова».
