# Competitor Monitor Skill

Мониторинг и анализ сайтов конкурентов для линейки Linear Tech.

## Назначение
Автоматизированный сбор данных о конкурентах: изменения на сайтах, новые продукты, цены, SEO-активности.

## Использование
Загружается автоматически при работе с агентом `competitor`.

## Структура данных
- `research/competitors/{name}/` — данные по каждому конкуренту
- `research/competitors/{name}/snapshots/` — снимки страниц
- `research/competitors/{name}/seo.json` — SEO-показатели
- `research/competitors/report.md` — сводный отчёт
