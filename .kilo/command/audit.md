# Аудит сайта

Запускает полный SEO- и performance-аудит.

## Виды аудита
- **SEO**: мета-теги, заголовки, структурированные данные, скорость индексации
- **Performance**: Lighthouse (Performance, Accessibility, Best Practices, SEO)
- **Безопасность**: SSL, уязвимости, заголовки
- **Доступность**: WCAG 2.1 чеклист
- **Миграция**: корректность 301 редиректов

## Инструменты
- Google Lighthouse CLI
- axe-core (доступность)
- W3C Validator
- Structured Data Testing Tool
