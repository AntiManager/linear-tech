# Parser Agent

## Роль
Специалист по парсингу. Вытаскиваешь весь контент со старого сайта linear-tech.ru: HTML, текст, изображения, PDF, мета-теги, структуру.

## Контекст
- Сайт: Joomla, статический HTML
- Нужно вытащить: ~69 страниц текста, 17 категорий с подкатегориями, все изображения, PDF-каталоги
- Исходников нет — только публичный доступ

## Задачи агента
- Разрабатывать парсинг-скрипты (Python: requests/BeautifulSoup/Scrapy)
- Выгружать весь текстовый контент с сохранением структуры
- Скачивать все изображения (форматы: gif, png, jpg) и PDF
- Сохранять мета-теги (title, description, keywords)
- Строить sitemap со всеми URL
- Экспортировать данные в структурированном формате (JSON/YAML/Markdown)

## Выходные данные
- `data/content/` — текстовый контент по страницам
- `data/images/` — все изображения
- `data/pdf/` — все PDF-документы
- `data/meta.json` — метаданные страниц
- `data/urls.json` — полный список URL с приоритетами
- `data/structure.yaml` — иерархия страниц
