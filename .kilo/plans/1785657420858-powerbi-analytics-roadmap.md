# План: атомарная докрутка модели «НДС»

**Дата:** 2026-08-02 | **Модель:** НДС (Power BI Desktop через MCP) | **Режим:** readwrite

## Принципы

- Каждый шаг = ровно 1 группа атомарных MCP-операций + 1 DAX-проверка
- Проверка ≈ всегда DAX-запрос: pass — идём дальше, fail — разбираемся, не идём дальше
- **MCP не имеет undo.** Перед каждой фазой: сохранить .pbix через Desktop (Ctrl+S), чтобы можно было откатиться из файла
- Меры в таблице `_Меры` не имеют собственного контекста строк — все CALCULATE/RELATEDTABLE в них служат для передачи контекста от измерений, **не удаляем их**

## Фаза 2: Консолидация календаря (ВЫСОКИЙ РИСК)

> **Перед стартом**: сохранить .pbix (Ctrl+S) и записать baseline-номера. При любом FAIL на шагах 2.1–2.9 — остановка, откат к сохранённому файлу, разбор причины.

### Общая логика
- У каждой факт-таблицы уже есть активная связь первичной даты → `_Календарь[Date]`
- Вторичные даты сейчас связаны с авто-таблицами LocalDateTable* — удаляем эти связи, заменяем на **неактивные** связи к `_Календарь[Date]`
- ПУПА: `Дата` (активная), `Дата входящего документа` и `Дата платежа` — обе неактивные
- Доступ к неактивным датам — через `CALCULATE(..., USERELATIONSHIP(...))` в отдельных мерах (Шаг 4.12)
- Только после переноса ВСЕХ связей удаляем LocalDateTable

### Шаг 2.0. Проверить непрерывность _Календарь

**Операция:** Проверить, что `_Календарь` не имеет пропусков (обязательно для Date Table):
```dax
EVALUATE
VAR _min = MIN('_Календарь'[Date])
VAR _max = MAX('_Календарь'[Date])
VAR _expected = DATEDIFF(_min, _max, DAY) + 1
VAR _actual  = COUNTROWS('_Календарь')
RETURN ROW("Min", _min, "Max", _max, "Expected_days", _expected, "Actual_rows", _actual, "OK", IF(_expected = _actual, "PASS", "FAIL — gaps!"))
```
**Pass-условие:** `Expected_days == Actual_rows`.

### Шаг 3.3. Создать универсальную меру ЗП_Все

**Операция:** Create measure `ЗП_Все` в `_Меры`, DisplayFolder=`06 - ЗП`, Description=`Зарплата менеджеров (база + бонусы) по таблице KPI`, Format=`#,0\ "₽"; ...`:
```
SUMX(
    KPI_Менеджеры,
    VAR _mgr = KPI_Менеджеры[Менеджер]
    VAR _pct = CALCULATE([План_%_менеджер], 'Спр_менеджер'[Основной менеджер] = _mgr)
    VAR _bonus_1 = IF(_pct >= 0.75, KPI_Менеджеры[Процент_при_75], 0)
    VAR _bonus_2 = IF(_pct >= 1, KPI_Менеджеры[Процент_сверх_100] * (_pct - 1), 0)
    VAR _bonus_OP = IF([План_%_ОП] >= 1 && _pct >= 0.75, KPI_Менеджеры[Процент_ОП], 0)
    RETURN
        KPI_Менеджеры[Базовая_ставка]
        + CALCULATE([РТ_Сумма_без_НДС] * _bonus_1, 'Спр_менеджер'[Основной менеджер] = _mgr)
        + CALCULATE([РТ_Сумма_без_НДС] * _bonus_2, 'Спр_менеджер'[Основной менеджер] = _mgr)
        + CALCULATE([РТ_Сумма_без_НДС] * _bonus_OP, 'Спр_менеджер'[Основной менеджер] = _mgr)
)
```

**Проверка:**
```dax
EVALUATE
ROW(
  "ZP_All", [ЗП_Все],
  "ZP_Sasha_old", [ЗП_Саша],
  "ZP_Nastya_old", [ЗП_Настя],
  "Old_sum", [ЗП_Саша] + [ЗП_Настя],
  "Delta", [ЗП_Все] - ([ЗП_Саша] + [ЗП_Настя])
)
```
**Pass:** |Delta| < 1 или Delta ≈ 0.

**Операция:** Create в `_Меры`, папка `00 - Time`, Description=`Выручка за аналогичный период прошлого года`:

```
CALCULATE([РТ_Сумма_без_НДС], SAMEPERIODLASTYEAR('_Календарь'[Date]))
```
**Проверка:**
```dax
EVALUATE SUMMARIZECOLUMNS('_Календарь'[Year], '_Календарь'[MonthNumber],
```

*(Revenue_LY должен быть не BLANK для месяцев с историческими данными.)*

#### Шаг 4.2. Revenue_YTD
**Операция:** Create в `_Меры`, папка `00 - Time`, Description=`Выручка с начала года (нарастающим итогом)`:

```
TOTALYTD([РТ_Сумма_без_НДС], '_Календарь'[Date])
```

#### Шаг 4.3. Revenue_MAT
**Операция:** Create в `_Меры`, папка `00 - Time`, Description=`Выручка за последние 12 месяцев (скользящий год)`:
```
CALCULATE([РТ_Сумма_без_НДС], DATESINPERIOD('_Календарь'[Date], MAX('_Календарь'[Date]), -12, MONTH))
```

**Проверка блока 4.1–4.3:**

```dax
EVALUATE
ROW("LY", IF(NOT ISERROR([Revenue_LY]), "PASS", "FAIL"),
```

### Блок 4B: P&L (4 меры)

#### Шаг 4.4. Gross_Margin + Gross_Margin_%
**Операция:** Create 2 меры в `01 - Продажи`:
```
Gross_Margin   = [РТ_Сумма_без_НДС] - [ПТУ_Сумма_без_НДС]
Gross_Margin_% = DIVIDE([Gross_Margin], [РТ_Сумма_без_НДС], 0)
```
*(Format: Gross_Margin — ₽, Gross_Margin_% — 0.0%)*

#### Шаг 4.5. Op_Profit + Op_Profit_%
**Операция:** Create 2 меры в `01 - Продажи`:
```
Op_Profit   = [Gross_Margin] - [ПУПА_Сумма_без_НДС] - [ПрРасх_Сумма]
Op_Profit_% = DIVIDE([Op_Profit], [РТ_Сумма_без_НДС], 0)
```
*(Format: Op_Profit — ₽, Op_Profit_% — 0.0%)*

**Проверка блока 4.4–4.5:**
```dax
EVALUATE SUMMARIZECOLUMNS('_Календарь'[Year],
    "Revenue", [РТ_Сумма_без_НДС], "COGS", [ПТУ_Сумма_без_НДС],
    "GM", [Gross_Margin], "GM_%", [Gross_Margin_%],
    "OP", [Op_Profit], "OP_%", [Op_Profit_%])
```

### Блок 4C: Воронка и конверсия (6 мер)

#### Шаг 4.6. Lead_Time_Avg
**Операция:** Create в `01 - Продажи`, Description=`Средний срок от заказа до отгрузки (дни)`:
```
CALCULATE(
    AVERAGEX(
        'Спр_ЗК',
        IF(NOT ISBLANK(RELATED('РТ_Основное'[Дата])),
           DATEDIFF(RELATED('ЗК_Основное'[Дата]), RELATED('РТ_Основное'[Дата]), DAY))
    )
)
```
*(Format: #,##0 "дн")*

#### Шаг 4.7. ЗК_Потеряно_кол + ЗК_Потеряно_сум
**Операция:** Create 2 меры в `01 - Продажи`:

`ЗК_Потеряно_кол` — Description: `Заказов без отгрузки`:
```
CALCULATE(
    DISTINCTCOUNT('ЗК_Основное'[Заказ клиента]),
    NOT('ЗК_Основное'[Заказ клиента] IN VALUES('РТ_Основное'[Заказ клиента]))
)
```

`ЗК_Потеряно_сум` — Description: `Сумма заказов без отгрузки, без НДС`:
```
CALCULATE(
    [ЗК_Сумма_без_НДС],
    NOT('ЗК_Основное'[Заказ клиента] IN VALUES('РТ_Основное'[Заказ клиента]))
)
```

#### Шаг 4.8. DSO_Avg
**Операция:** Create в `03 - Деньги`, Description=`Средний срок от отгрузки до оплаты (дни)`:
```
CALCULATE(
    AVERAGEX(
        'Спр_ЗК',
        VAR _ship = RELATED('РТ_Основное'[Дата])
        VAR _pay  = CALCULATE(MIN('Поступление_ДС'[Дата]))
        RETURN IF(NOT ISBLANK(_ship) && NOT ISBLANK(_pay), DATEDIFF(_ship, _pay, DAY))
    )
)
```
*(Format: #,##0 "дн")*

**Проверка блока 4.6–4.8:**
```dax
EVALUATE
ROW("Lead_Time", [Lead_Time_Avg], "Lost_cnt", [ЗК_Потеряно_кол],
    "Lost_sum", [ЗК_Потеряно_сум], "DSO", [DSO_Avg])
```
*(Между 0 и 365, потерянные ≤ общие ЗК.)*

### Блок 4D: Клиентская аналитика (3 меры)

#### Шаг 4.9. Active_Clients + ARPU + Avg_Orders_Per_Client
**Операция:** Create 3 меры в `05 - Клиенты`:
```
Active_Clients         = DISTINCTCOUNT('РТ_Основное'[Клиент])
ARPU                   = DIVIDE([РТ_Сумма_без_НДС], [Active_Clients], 0)
Avg_Orders_Per_Client  = DIVIDE([РТ_кол-во_зк], [Active_Clients], 0)
```
*(Format: Active_Clients — #,##0, ARPU — ₽, Avg_Orders — 0.0)*

**Проверка:**
```dax
EVALUATE SUMMARIZECOLUMNS('_Календарь'[Year],
    "Clients", [Active_Clients], "ARPU", [ARPU], "Avg_orders", [Avg_Orders_Per_Client])
```

### Блок 4E: План-факт (2 меры)

#### Шаг 4.10. Plan_Completion_% + Plan_Gap
**Операция:** Create 2 меры в `04 - План`:

