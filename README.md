# Linear Tech — Полная переделка сайта

**Клиент**: ООО "Линейные системы" (Екатеринбург) — официальный дистрибьютор HIWIN в России.

**Старый сайт**: [linear-tech.ru](https://www.linear-tech.ru) (Joomla, 2011 г.)
**Новый сайт**: стек определяется, VPS клиента.

## Структура репозитория

```
.kilo/                   # Конфигурация Kilo AI
├── agent/               # Специализированные AI-агенты
│   ├── architect.md     #   Архитектор
│   ├── designer.md      #   UI/UX дизайнер
│   ├── parser.md        #   Парсер контента
│   ├── seo.md           #   SEO-специалист
│   ├── marketer.md      #   Маркетолог
│   └── competitor.md    #   Аналитик конкурентов
├── command/             # Слэш-команды (/scrape, /deploy, /audit)
├── skill/               # Скиллы
│   └── competitor-monitor/
├── setup-script.ps1     # Скрипт установки для Agent Manager
├── run-script.ps1       # Скрипт запуска для Agent Manager
├── data/                # Парсенные данные со старого сайта
│   ├── content/         #   Текстовый контент по страницам
│   ├── images/          #   Изображения
│   └── pdf/             #   PDF-документы
├── docs/                # Документация проекта
│   ├── architecture/    #   Архитектурные решения
│   └── decisions/       #   ADR (Architecture Decision Records)
├── research/            # Исследования и анализ
│   └── competitors/     #   Данные по конкурентам
├── AGENTS.md            # Глобальные инструкции
├── kilo.json            # Конфигурация Kilo
└── README.md            # Этот файл
```

## Команды

- `/scrape` — запустить парсинг старого сайта
- `/deploy` — деплой на VPS
- `/audit` — SEO/performance аудит
- `/backup` — бэкап (будет добавлен)
