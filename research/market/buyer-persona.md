# Портрет заказчика и лиц принимающих решения (ЛПР)

**Дата**: 2026-07-25
**Рынок**: B2B промышленная механика

---

## 1. Типичный путь закупки

```
[Проблема] → [Поиск в Google/Яндекс] → [Звонок/Заявка в 2-3 компании] → [Сравнение цен + наличие] → [Счёт] → [Оплата] → [Доставка]
```

Для OEM-сегмента путь длиннее:
```
[ТЗ на разработку] → [Подбор компонентов инженером] → [Согласование спецификации] → [Запрос КП у 2-3 поставщиков] → [Тендер/выбор] → [Договор] → [Поставка]
```

---

## 2. Роли в принятии решения

### 2.1. Инженер-конструктор / технолог (технический инициатор)
**Должности**: Инженер-конструктор, главный конструктор, технолог, разработчик
**Возраст**: 30-55 лет
**Образование**: Высшее техническое (МГТУ им. Баумана, УрФУ, МАИ, СПбПУ и др.)
**Роль**: *Определяет, ЧТО покупать*
**Задачи**:
- Подбирает компоненты под ТЗ (серия, размер, класс точности)
- Ищет каталоги, PDF, характеристики
- Сравнивает по техническим параметрам
- Может знать конкретного поставщика по предыдущему опыту
**Болевые точки**:
- Каталоги на английском, неудобно
- Нет фильтрации по параметрам
- Нет возможности быстро сравнить 3-4 варианта
- Чертежи и 3D-модели не скачать
- Техподдержка "только менеджеры" (не разбираются)

### 2.2. Снабженец / Закупщик (экономический ЛПР)
**Должности**: Менеджер по закупкам, начальник отдела закупок, специалист по снабжению
**Возраст**: 28-50 лет
**Роль**: *Определяет, ГДЕ купить*
**Задачи**:
- Ищет лучшую цену среди нескольких поставщиков
- Собирает коммерческие предложения
- Проверяет наличие на складе и сроки
- Запрашивает счёт, договор
**Болевые точки**:
- Нет цен на сайте (приходится звонить/писать)
- Долгий ответ от поставщика
- Нет онлайн-статуса наличия
- Сложно сравнить цены (у всех разная подача)
- Нельзя оформить заказ онлайн

### 2.3. Директор / собственник (финальное решение)
**Должности**: Генеральный директор, технический директор, собственник
**Возраст**: 35-60 лет
**Роль**: *Утверждает бюджет*
**Задачи**:
- Оценивает надёжность поставщика
- Проверяет реквизиты, отзывы, сайт
- Утверждает сделку при крупных суммах (>100 тыс. руб.)
**Болевые точки**:
- Непонятно, оригинал или копия
- Нет сертификатов/гарантии на сайте
- Сайт выглядит ненадёжно → не буду работать

### 2.4. Начальник производства / главный механик (инициатор ремонта)
**Должности**: Главный механик, начальник цеха, наладчик
**Возраст**: 30-55 лет
**Роль**: *Инициирует срочную закупку*
**Задачи**:
- Станок сломался / износилась направляющая → нужно СРОЧНО
- Обзванивает всех подряд
- Ищет "по образцу" — фотка, старая деталь
**Болевые точки**:
- Нет кнопки "срочный заказ"
- Непонятно, есть ли на складе прямо сейчас
- Нет доставки день-в-день

## 3. Психологический портрет

| Характеристика | Значение |
|---------------|----------|
| **Ценности** | Надёжность, техническая грамотность, конкретность |
| **Тон общения** | Экспертный, без "продажных" приёмов |
| **Что раздражает** | Скрытые цены, "менеджер перезвонит", неработающий поиск |
| **Что радует** | Быстрый ответ, цены на сайте, техподдержка инженера, PDF и чертежи |
| **Откуда узнают** | Поисковики (70%), коллеги/партнёры (20%), выставки (10%) |
| **Принимает решение за** | 1 день (срочный ремонт) — 3 месяца (OEM-поставка) |

## 4. User Stories (пользовательские сценарии)

### Сценарий 1: Инженер подбирает направляющие для нового станка
```
Алексей, 34 года, инженер-конструктор на станкостроительном заводе в Екатеринбурге.
Задача: Подобрать направляющие HIWIN HG25 и ШВП для нового токарного станка с ЧПУ.

1. Гуглит: "направляющие HIWIN HG25 купить"
2. Попадает на сайт, ищет в каталоге HG25
3. Смотрит характеристики: грузоподъемность, габариты, класс точности
4. Скачивает PDF-каталог и чертёж
5. Смотрит цену (хотя бы ориентировочную)
6. Пишет в чат/форму: "Нужна консультация по подбору"

Ожидания: Каталог с фильтром по серии, размеру, PDF и чертежи на странице товара, чат с инженером.
```

### Сценарий 2: Главный механик срочно меняет ШВП
```
Виктор, 48 лет, главный механик на заводе в Челябинске.
Задача: Сломалась ШВП на станке — производство стоит, нужна замена СЕГОДНЯ.

1. Звонит другу-снабженцу: "Где брали HIWIN?"
2. Заходит на сайт, вбивает в поиск маркировку ШВП
3. Видит цену и наличие на складе (или: "под заказ 4 недели")
4. Если есть в наличии — звонит, просит отложить, едет забирать
5. Если нет — ищет дальше

Ожидания: Поиск по маркировке, онлайн-статус наличия, срочная доставка день-в-день.
```

### Сценарий 3: Снабженец собирает коммерческие предложения
```
Ольга, 37 лет, менеджер по закупкам в машиностроительном холдинге.
Задача: Прислали спецификацию на 12 позиций (направляющие, ШВП, муфты). Нужны КП.

1. Открывает 3-4 сайта конкурентов
2. Вбивает каждую позицию в поиск
3. У конкурентов нет цен → пишет запросы
4. На сайте с ценами — сразу видит, сравнивает
5. Отправляет "корзину" в КП (если есть такая функция)

Ожидания: Цены на сайте, возможность скачать КП из корзины, быстрый ответ на запрос.
```

## 6. Ключевые выводы для сайта

| Что нужно | Почему |
|-----------|--------|
| **Цены на сайте** | Экономит 1 день на каждый запрос снабженца. Прямой конкурент техноберинг и зетек уже показывают цены |
| **Поиск по маркировке/артикулу** | Инженеры ищут "HG25", "FSI32-10", а не "направляющие HIWIN" |
| **Онлайн-статус наличия** | Критично для ремонтного сегмента (20% выручки) |
| **PDF и чертежи на странице товара** | Инженер скачивает и вставляет в проект |
| **Формат "быстрая заявка"** | Для ремонтников: телефон + "пришлите фото детали" |
| **Корзина → КП одним кликом** | Для снабженцев: собрал → получил коммерческое предложение |
| **Технический чат/консультант** | Инженеры ценят разговор с инженером, а не с "менеджером" |
