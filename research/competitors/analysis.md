## 2. Сравнительный анализ сайтов

### 2.1. Linearmotion.ru — лучший референс
**CMS**: WordPress (свой шаблон)
**Сильные стороны**:
- Современный адаптивный дизайн (clean, industrial)
- Чёткая структура каталога (4 категории, 107+ товаров)
- Карточки товаров с фото, характеристиками, артикулами
- Часто задаваемые вопросы (FAQ) на главной
- Форма обратной связи с номером телефона
- Яндекс.Метрика для аналитики

**Слабые стороны**:
- Нет цен на сайте (только "узнать цену")
- Нет личного кабинета
- Мало контента (почти нет статей)
- Медленная загрузка

### 2.2. Приводная Техника (privod.ru) — гигант
**CMS**: 1С-Битрикс
**Сильные стороны**:
- Огромный каталог (20+ категорий, сотни товаров)
- Подбор оборудования по параметрам
- Категории по отраслям (пищевая, сельхоз, ЖКХ и т.д.)
- Пресс-центр: новости, статьи, книги
- Документация и сертификаты
- EN-версия сайта
- Сервисная служба: гарантия, ремонт

**Слабые стороны**:
- Тяжёлый, перегруженный интерфейс
- Сложная навигация (глубокие подменю)
- Устаревший дизайн
- Неочевидный путь до покупки

### 2.3. Proma (proma.su) — best in class B2B e-commerce
**CMS**: Self-made
**Сильные стороны**:
- Полноценный интернет-магазин с ценами, корзиной
- Удобные фильтры по категориям
- Хиты продаж и лидеры на главной
- B2B-функционал (цены для юрлиц)
- Программы лояльности: рассрочка, лизинг
- Техническая поддержка и сервис
- ЧПУ и оснастка в одном месте

**Слабые стороны**:
- Proma — это бренд станков, не компонентов
- Дизайн мог быть современнее
- Нет контент-маркетинга

### 2.4. Техноберинг (technobearing.ru) — прямой конкурент
**CMS**: 1С-Битрикс
**Сильные стороны**:
- Огромный каталог с ценами (в рублях)
- Детальная категоризация: подшипники, ШВП, направляющие, валы, муфты, рейки
- В каждой категории — десятки/сотни позиций (например, 266 подшипников скольжения серии GE)
- Есть интеграция с 1С (корзина, оформление заказа)
- Акции на сайте
- Каталоги PDF для скачивания
- Справочник/guide (полезный контент)
- Технический сервис (механическая обработка)
- Социальные сети: VK, Telegram, Дзен, Youtube, Rutube

**Слабые стороны**:
- Устаревший дизайн
- Сложная навигация (глубокие подменю, трудно найти нужное)
- Неочевидные названия разделов (eshop1 в URL)
- Нет фильтрации по параметрам (только поиск + дерево категорий)
- Нет адаптивности на всех страницах
- Медленная загрузка
- Нет личного кабинета B2B

### 2.5. Русбелт (rusbelt.ru) — лучший B2B e-commerce
**CMS**: 1С-Битрикс
**Сильные стороны**:
- Полноценный интернет-магазин
- B2B: цены для юрлиц, кредит, отсрочка
- Богатый каталог с фильтрацией
- Акции и скидки
- Кабинет клиента
- Социальные сети (VK, Telegram, Дзен, Rutube)

**Слабые стороны**:
- Другая ниша (конвейерные ленты ≠ прецизионная механика)
- Узкий ассортимент по направляющим/ШВП

| Отраслевые решения | ❌ | Приводная Т. |

### Ключевые возможности для дифференциации

1. **SKU-каталог с фильтрацией** — ни у кого из прямых конкурентов нет удобного каталога с фильтром по параметрам для HIWIN-продукции (тип, размер, грузоподъемность)

2. **Технический контент + SEO** — у linearmotion.ru и linear-tech.ru почти нет полезных статей, гайдов по подбору. Это мощный канал для B2B-трафика

3. **Цены и online-заказ** — даже частичный показ цен (ориентировочные) + корзина дадут сильное преимущество

4. **3D-модели и чертежи** — инженеры ценят возможность скачать STEP-модель перед покупкой

5. **Подбор по аналогам** — "заменитель THK → HIWIN" — сильное УТП

6. **Отраслевые решения** — как у Приводной Техники, но для прецизионной механики

## 4. Рекомендации для нового сайта

### Обязательно
- [x] Современный адаптивный дизайн (industrial-стилистика)
- [x] Каталог с фильтрацией по параметрам
- [x] Карточки товаров с фото, описанием, PDF
- [x] Цены (хотя бы ориентировочные)
- [x] Форма заявки + обратный звонок
- [x] Яндекс.Метрика + GA4
- [x] Schema.org (Product, Organization, BreadcrumbList)

### Желательно (для отрыва от конкурентов)
- [ ] 3D-модели и STEP-файлы для скачивания
- [ ] Подбор по аналогам (HIWIN ↔ THK ↔ NSK)
- [ ] B2B-кабинет (история заказов, счета)
- [ ] FAQ по каждой категории
- [ ] Технические статьи и гайды по подбору
- [ ] Отраслевые разделы (металлообработка, деревообработка, робототехника)
- [ ] API для интеграции с 1С/CRM

### Не делать как конкуренты (anti-patterns)
- Копировать устаревший дизайн Приводной Техники
- Прятать все контакты в футер (как Proma частично)
- Игнорировать мобильную версию
- SEO-спам в футере (как на текущем linear-tech.ru)
