# Сравнение технологических стеков — Linear Tech

**Дата**: 2026-07-25
**Задача**: Выбрать стек для нового сайта linear-tech.ru

---

## 1. Кандидаты

### A. Next.js 16 + Strapi 5.51 (Headless CMS) — ⭐5 Рекомендовано
```
Frontend:  Next.js 16 App Router + React 19 RSC + Tailwind CSS 4
Backend:   Strapi 5.51 (self-hosted, MIT license)
DB:        PostgreSQL 16
Search:    Meilisearch (MIT) или PostgreSQL full-text + pg_trgm
Cache:     Redis 7
CDN:       Cloudflare Free plan
Deploy:    Docker Compose на VPS
```

| Критерий | Оценка | Комментарий |
|----------|:------:|-------------|
| Производительность | ⭐⭐⭐⭐⭐ | SSG для каталога (мгновенная загрузка), ISR для обновления. Lighthouse 90+ достижим. |
| Стоимость владения | ⭐⭐⭐⭐⭐ | Только хостинг VPS (~1 200 ₽/мес). Всё ПО — Open Source. |
| Гибкость дизайна | ⭐⭐⭐⭐⭐ | Полный контроль над HTML/CSS. Tailwind — любой pixel-perfect дизайн. |
| SEO | ⭐⭐⭐⭐⭐ | RSC (React Server Components) — HTML рендерится на сервере, отлично для поисковиков. |
| Безопасность | ⭐⭐⭐⭐ | TypeScript исключает класс ошибок. Регулярные обновления npm. |
| Интеграция с Б24 | ⭐⭐⭐ | REST API + webhooks. Требуется написать адаптер (1-2 дня). |
| Экосистема | ⭐⭐⭐⭐⭐ | Next.js — самый популярный React-фреймворк. Огромное комьюнити. |

**Почему выбрали**:
- Максимальная производительность из всех вариантов
- Open Source = нет лицензионных отчислений
- Полный контроль над UX (конкуренты на Битриксе выглядят одинаково — мы выделимся)
- Strapi — удобная админка для менеджеров (контент, товары, цены — без программиста)
- Vercel/Netlify не обязателен — работает на своём VPS через Docker

**Риски и митигация**:
- Нужен React-разработчик → есть я + GitHub Copilot
- Деплой сложнее PHP → Docker Compose решает
- Битрикс24 интеграция ручная → REST API Битрикс24 документирован

### B. Astro 5 + Strapi 5 — ⭐4½ Альтернатива Next.js
```
Frontend:  Astro 5 + React Islands (для интерактива)
Backend:   Strapi 5
DB:        PostgreSQL 16
Deploy:    Статический HTML + API на VPS
```

| Критерий | vs Next.js | Комментарий |
|----------|:----------:|-------------|
| Производительность | **Лучше** | Astro отправляет 0 KB JS по умолчанию. Идеально для каталога (страницы без интерактива). |
| Сложность | **Проще** | Меньше концепций (нет Server Components, проще модель). |
| Интерактивность | Хуже | Фильтры, поиск, корзина — требуют React Islands. Может стать сложнее. |
| SEO | Так же | Статический HTML по умолчанию. |
| Экосистема | Меньше | Меньше плагинов и готовых компонентов чем у Next.js. |

**Вердикт**: Отличный выбор если каталог статический. Но из-за интерактивных фильтров и корзины — Next.js практичнее.

### C. Django 5 + Templates + HTMX — ⭐4

| Критерий | Оценка | Комментарий |
|----------|:------:|-------------|
| Производительность | ⭐⭐⭐⭐ | Серверный рендеринг быстрый, но нет SSG. Каждая страница = запрос к серверу. |
| Стоимость | ⭐⭐⭐⭐⭐ | Только VPS. Всё Open Source. |
| Гибкость | ⭐⭐⭐ | Django Templates ограничены. HTMX решает интерактив, но непривычно. |
| SEO | ⭐⭐⭐ | HTML генерится на сервере. Хорошо, но не идеально (нет статической предзагрузки). |
| Админка | ⭐⭐⭐⭐⭐ | Django Admin — лучшая из коробки. Менеджеры оценят. |
| Экосистема | ⭐⭐⭐⭐ | Python — огромное комьюнити. Но фронтенд-часть слабее JS-экосистемы. |

**Вердикт**: Хорошо, если команда Python-only. Next.js даёт лучший UX при той же цене.

### D. 1С-Битрикс (редакция «Бизнес») — ⭐⭐⭐

| Критерий | Оценка | Комментарий |
|----------|:------:|-------------|
| Производительность | ⭐⭐ | Тяжёлый монолит. LCP редко ниже 3с. Нужен агрессивный кеш. |
| Стоимость | ⭐⭐ | Лицензия ~150 000 ₽/год + хостинг. За 3 года ~500 000 ₽ только лицензия. |
| Гибкость | ⭐⭐ | Привязан к шаблонам. Кастомизация — боль и PHP. |
| Интеграции | ⭐⭐⭐⭐⭐ | 1С + Битрикс24 из коробки. |
| Безопасность | ⭐⭐⭐ | Много CVE. Требуется постоянное обновление. |

**Вердикт**: Единственный плюс — интеграция с 1С/Б24 из коробки. Остальное — компромисс. Лицензия съедает бюджет. Дизайн будет как у всех (техноберинг, зетек, кугелтрейд — все на Битриксе).

### E. WordPress + WooCommerce — ⭐⭐½

| Критерий | Оценка | Комментарий |
|----------|:------:|-------------|
| Производительность | ⭐⭐ | Без кеширования — медленно. С кешированием (WP Rocket) — средне. |
| Стоимость | ⭐⭐⭐⭐ | Бесплатно. Плагины могут стоить денег. |
| Гибкость | ⭐⭐⭐ | Много тем и плагинов. Кастомизация = PHP. Gutenberg редактор спорный. |
| Безопасность | ⭐⭐ | Самая атакуемая CMS в мире. Требует постоянного мониторинга. |

**Вердикт**: Не для промышленного B2B каталога. WordPress хорош для блогов и простых сайтов.

## 3. Итоговая рекомендация

**🥇 Next.js 16 + Strapi 5.51 + PostgreSQL + Meilisearch**

### Что это даёт бизнесу:
1. **Скорость сайта** — инженер найдёт деталь за 5 секунд (поиск по артикулу + SSG/ISR + TurboPack)
2. **Экономия** — 150 000 ₽/год на лицензии Битрикса уходит в карман, а не вендору
3. **Выделяемся** — дизайн будет современным, не как у всех конкурентов на Битриксе
4. **Менеджеры счастливы** — Strapi админка проще Битрикса, обновлять контент легко
5. **SEO** — Google видит готовый HTML (React Server Components), индексация мгновенная

### Что нужно для запуска:
- VPS: Ubuntu 22.04, 4 GB RAM, 2 vCPU, 50 GB SSD (~1 200 ₽/мес у Reg.ru/Timeweb)
- Docker + Docker Compose
- Домен + SSL (Let's Encrypt)
- GitHub Actions для CI/CD
- Разработчик React/Next.js (я)
