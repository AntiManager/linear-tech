# Аксессуары для профиля

Крепежные элементы вставляются в Т-пазы профиля для соединения одного отрезка профиля с другим или для крепления к профилю других сборочных компонентов конструкции.

## Аксессуары для конструкционного профиля

Крепежные элементы вставляются в Т-пазы профиля для соединения одного отрезка профиля с другим или для крепления к профилю других сборочных компонентов конструкции.

Применение специальных крепежных элементов не требует предварительной подготовки и обработки профиля, за исключением распила на требуемые по проекту длины отрезков.

Различные виды крепежа обеспечивают выбор более удобных способов установки и обеспечения необходимой нагрузки несущей конструкции.

Угловые соединители 90°

Угловые соединители с центрирующими язычками для быстрой и точной сборки изделия с предохранением от скручивания. Обеспечивают простое соединение под прямым углом при минимальном наборе инструментов. При использовании данных угловых соединений сборка конструкций осуществляется без предварительной подготовки профиля.

Материал: алюминий, литой под давлением, отшлифованный методом вибрационного шлифования.

Доступные размеры:

- Для профиля с шириной паза 8 мм

- 30/30

- 30/60

- Для профиля с шириной паза 10 мм

- 40/40

- 40/80

- 45/45

- 45/90

- 80/80

Т-гайка

T-гайка – это стандартный элемент для прочностного и электропроводящего соединения. Для корректирования положения в пазу профиля используется специальный упор на гайке. Предварительная подготовка профиля для монтажа болта не требуется.

Для профиля с шириной паза 8,2 мм предназначены гайки М6, для профиля с шириной паза 10,2 мм - гайки М8.

Материал Т-образной гайки – никелированная сталь.

Т-болт

T-болт – это надежное и электропроводящее соединение. Для корректирования положения в пазу профиля используются засечки по торцам винта. Для удобства применения Т-болта рекомендуется использовать фланцевую гайку. Предварительная подготовка профиля для монтажа болта не требуется.

Для профиля с шириной паза 8,2 мм предназначены болты М6, для профиля с шириной паза 10,2 мм - болты М8.

Материал Т-образного болта и гайки с фланцем – никелированная сталь.
