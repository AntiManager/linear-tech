# Катаные ШВП (каталог)

Катаные ШВП имеют класс точности C7 по ISO, DIN (0,052 мм на длине 300 мм). Поставляются со склада - без обработки посадочных мест с фланцевыми гайками (DIN 69051) типов FSI, FSC. С обработкой концевиков - под заказ. Каталог содержит информацию по типам: FSI, SE, DEB, DDB, ZE, ZD.
