# Linear Tech — Полная переделка сайта

## Проект
Переделка сайта **linear-tech.ru** (ООО "Линейные системы", Екатеринбург) — дистрибьютор промышленной механики HIWIN.
Перенос на VPS клиента. Исходников нет — весь контент парсим с живого сайта.

## Текущий статус
- **Старый сайт**: https://www.linear-tech.ru (Joomla, кастомный шаблон jblank)
- **Хостинг**: VPS клиента (будет определён)
- **Стек**: Next.js 14 + Strapi 5 + PostgreSQL 16 + Meilisearch + Docker

### Архитектура стека
```
Frontend:  Next.js 16 (App Router) + React 19 RSC + Tailwind CSS 4 + TypeScript
CMS:       Strapi 5.51 (Headless, self-hosted, MIT)
Database:  PostgreSQL 16
Search:    Meilisearch (full-text search по артикулам/товарам)
Cache:     Redis 7
DEV:       Docker Desktop 29 (Windows) для локальной разработки
Deploy:    Docker Compose на Ubuntu VPS + GitHub Actions CI/CD
CDN:       Cloudflare (free)
CRM:       Интеграция с Битрикс24 через REST API (последний этап — пока заглушки)
```

## Текущий прогресс (26.07.2026)

### Инфраструктура
- Docker dev stack: 5 сервисов (postgres, redis, meilisearch, strapi, nextjs)
- Dockerfile.dev для Strapi (node:22-slim) и Next.js (node:22-alpine)
- GitHub: https://github.com/AntiManager/linear-tech (8 коммитов на master)
- Пуш актуален: `fffba46..c746333 master -> master`

### Контент в Strapi
- 17 категорий, 53 продукта, 23 статьи (93 записи)
- Все записи привязаны к изображениям (из data/images-webp/, 202 WebP)
- 53 продукта привязаны к категориям
- Имена категорий очищены от SEO-мусора (14 из 17)
- `# Заголовки`, `\r`, битые PDF-ссылки вычищены из всех описаний

### Фронтенд (Next.js 16)
- **Главная**: 17 карточек категорий с реальными изображениями, hero «Официальный представитель HIWIN», trust-блок
- **Каталог**: фильтры по сериям/наличию, поиск по артикулам, серверные + клиентские компоненты
- **Карточка товара**: интерактивные табы (ProductTabs), JSON-LD, CTA «Запросить КП»
- **RFQ**: корзина → форма → API, бейдж с реактивным счётчиком
- **SEO**: robots.ts, sitemap.ts, structured data на товарах
- **Markdown**: контент из Strapi конвертируется через marked → mdToHtml()
- **Лейаут**: CTA-секция на всех страницах, футер с 17 категориями из Strapi
- **Страницы**: /about (сторителлинг), /contacts, /production, /partners, /catalog, /rfq

### Известные проблемы
- Часть продуктовых страниц — 404 в dev-режиме (generateStaticParams + Turbopack)
- `\r` не полностью вычищены (~12 артефактов в статьях, косметика)
- Нет продакшен-сборки (VPS не настроен, CI/CD заглушки)
- Интеграция с Битрикс24 — заглушка
